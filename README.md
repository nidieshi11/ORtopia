# ORtopia

[ORtopia home](https://nidieshi11.github.io/ORtopia/) · [Dataset](https://nidieshi11.github.io/ORtopia/dataset/) · [Simulation](https://nidieshi11.github.io/ORtopia/simulation/)

Dataset and Simulation open in English. Use the language link inside either section to switch between English and Chinese at the same problem or replay step.

在 Dataset 的[中文领域目录](https://nidieshi11.github.io/ORtopia/dataset/?lang=zh#/domains)中可以查阅题目、场景图、数学模型和问题描述，在[论文集](https://nidieshi11.github.io/ORtopia/dataset/?lang=zh#/library)中可以按系列和期刊浏览原文 PDF。

Simulation 按 14 类业务场景列出 206 个仿真实例。选择场景后，点击实例名称即可播放。181 个中等规模实例使用 medium/I001，每个实例的决策变量与约束均达到一万。其余 25 个实例提供各自的交互操作。

## Dataset and Simulation

Dataset contains the subject directory and paper library. Browse problems, scene illustrations and mathematical models by research area, or find a paper by journal series and open its PDF.

Browse 206 simulations across 14 application areas in Simulation. Select an area and an instance to open its player. The collection includes 181 medium-scale instances with at least 10,000 decision variables and 10,000 constraints each, alongside 25 simulations with dedicated interactive controls.
