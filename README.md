# ORtopia

[打开实例仿真](https://nidieshi11.github.io/ORtopia/)

首页按 14 类业务场景列出 206 个仿真实例。选择场景后，点击实例名称即可播放。181 个中等规模实例使用 medium/I001，每个实例的决策变量与约束均达到一万。其余 25 个实例提供各自的交互操作。

## Instance simulations

Browse 206 simulations across 14 application areas on the home page. Select an area and an instance to open its player. The collection includes 181 medium-scale instances with at least 10,000 decision variables and 10,000 constraints each, alongside 25 simulations with dedicated interactive controls.
