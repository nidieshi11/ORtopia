P82: Original multi-stage stochastic integer programming with non-forward-looking policies

Source and scope Based on pages 1, 8, 9, and 10 of the original paper PDF, sections 2 (Formulas (1a)–(1c)) and Xt definitions; assumption 1–2 on page 8; and non-prospective interpretation on page 10.

Modeling objects and information structures Retain the original multi-stage stochastic mixed integer programming (MSMIP) formulations (1a)–(1c) from Section 2 of the paper. The stage-based and non-forwarding Lagrangian duality are methods for finding the lower bound of the problem, and do not belong to another set of decision models in this document. The stage set is T = {1,…,T}. In the probability space (Ω,F, ℙ), the stage random vector is ξt ∈ ℝℓt, the history is ht = (ξ1,…,ξt), the dimension of history is Lt = ∑ ⁡ s=1tℓs; ξ1 = 1 is determined in the first stage. Ft = σ(ht) and the distribution of the complete path and the support set Ξ are both inputs. The joint distribution of the stage random vectors is given by the instance and may include inter-stage dependencies.

Parameters In stage t, the decision dimension is nt. The first pt components are integers, while 0 ≤ pt ≤ nt. The number of rows for the state equation and inequalities within the stage are mts,mtr. All the measurable coefficients depend solely on the known history of ht:

ct(ht) ∈ ℝnt ,bt(ht) ∈ ℝmts ,dt(ht) ∈ ℝmtr , At(ht) ∈ ℝmts×nt ,Bt(ht) ∈ ℝmts×nt−1 ,Ct(ht) ∈ ℝmtr×nt .

ct represents the cost vector, At,Bt,bt describes the state coupling between the current and previous periods, Ct,dt describes the resources, boundaries, and other feasibility conditions for the current period. The paper specifies x0(h0) ≡ 0; non-zero initial resources and other constants must be input as part of b1, the initial state is fixed by the instance.

Variable and phase feasible regions The variable is not a forward-looking policy xt : ht↦xt(ht). That is, xt must be Ft measurable, and the same decision should be adopted across the same history. The complete feasible region within the phase is

Xt(ht) = {x ∈ ℤpt × ℝnt−pt : Ct(ht)x ≥ dt(ht)}.

If the non-negative nature of the variables, their upper and lower limits, as well as their binary nature are required for a particular instance, these details must be explicitly specified by the instance using the Ct,dt notation.

Among these, the ranges (1c–i) to (1c–ii) only involve expanding on the original expression for (1c). The symbol (NA) indicates that the definitions of the policy variables remain unchanged. No additional optimization problems were introduced.

Enter applicable conditions and details regarding the limited number of instances available. According to pages 8–9 of the paper, assume that relative complete remedies are possible: any feasible past decisions are also feasible in the current period. Additionally, Xt(ht) is almost always tight, and 𝔼[diam ⁡ (Xt(ht))] < ∞ is also true. At the same time, the expected cost should be well-defined. These conditions serve as input assumptions for this problem; they do not allow for the arbitrary addition of slack variables, penalties, or other constraints to modify individual instances.

If the input is represented using a finite scenario tree, then each node represents a historical situation, and the nodes share the same decision-making processes. This is not a forward-looking description; the probability of reaching a given node must be considered as an unconditional probability. The sum of the probabilities for leaf nodes is always equal to 1. The probability for any non-leaf node is equal to the sum of the probabilities of its child nodes. If the tree fully represents the original input distribution, then it represents a finite representation of the same model. If the tree is merely a sample, then it can only represent an instance of that discrete approximate distribution. No second set of mathematical models is provided in this description.
