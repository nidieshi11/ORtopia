Robust dynamic assortment optimization with a known contamination upper bound

Objective and admissibility

The selected performance objective is to minimize the Typically-Optimal-Typically-Evaluated (TOTE) regret by an admissible sequential assortment policy:

Regret ⁡ TOTE(T) := 𝔼 [∑ t=1TR(S∗;{v}) − R(S t;{v})]. 		(2)

The subject-to conditions on the retailer’s decisions are

St ⊆ [N],|St|≤ K,St = 𝔓t({Sτ,iτ}τ≤t−1),t = 1,2,…,T,

where the T random functions 𝔓1,…,𝔓T constitute an admissible policy as specified below. The benchmark is

S∗ = arg ⁡ max ⁡ S⊆[N],|S|≤KR(S;{v}).

TOTE evaluates both assortments using the typical-customer model even at times when the arriving customer is an outlier. This is the performance criterion selected by the paper for its upper-bound analysis, rather than the alternative best-in-hindsight criterion.

Inputs, choice model, and information protocol

There are N items and T customer-arrival periods. The capacity parameter is K. The item parameters satisfy

ri ∈ [0,1](known revenue),vi ∈ [0,1](unknown utility),i ∈ [N].

The true contamination parameter and the known upper bound have distinct roles:

𝜀 ∈ [0,1),𝜀¯ ≥ 𝜀,

with 𝜀¯ supplied to Algorithm 1. The selected utility normalization is vi ∈ [0,1], not the optional larger-upper-bound variant discussed on page 7.

At time t, the observed purchase satisfies

it ∈ St ∪{0},t = 1,…,T.

A purchase of item it ∈ St produces revenue rit; it = 0 denotes no purchase and produces no revenue. For a typical customer,

Pr ⁡ [it = i∣St] = vi v0 + ∑ j∈Stvj,v0 = 1, 		(1)

for purchase outcomes i ∈ St ∪{0}. Thus no purchase is a most probable outcome for a typical customer. An outlier instead purchases according to an arbitrary unknown distribution Qt, marginalized on St ∪{0}; Qt may change with t.

The source’s assumptions (A1)–(A2) and Definition 1 specify the adversary and the information available to the retailer. Let

ϕt ∈{0,1},t = 1,2,…,T,

where ϕt = 1 means an outlier and ϕt = 0 means a typical customer. Bounded contamination means

∑ t=1Tϕ t ≤ 𝜀T. (A1)

The adaptive adversary consists of T arbitrary measurable functions 𝔄1,…,𝔄T with

Ft−1 = {ϕτ,Qτ,Sτ,iτ}τ≤t−1, 𝔄t : {ϕτ,Qτ,Sτ,iτ}τ≤t−1⟼(ϕt,Qt),t = 1,…,T. (A2 / Definition 1)

Thus outlier arrivals and choice models can depend on previous customers, offered assortments, and past purchasing activity. The retailer’s policy has the smaller information history

Gt−1 = {Sτ,iτ}τ≤t−1, 𝔓t : {Sτ,iτ}τ≤t−1⟼St,St ⊆ [N],|St|≤ K,t = 1,…,T.

If ϕt = 0, it is realized according to (1), conditioned on St; if ϕt = 1, it is realized according to Qt. The retailer is not given the outlier indicators or the outlier distributions.

Linked assortment computation: Section 4.1 and Algorithm 2

This is the computation invoked by Algorithm 1, not a replacement objective for the sequential problem. At an invocation, the candidate items are the current A(τ), the utilities are the current v^(τ), and the required item is i ∈A(τ). Section 4.1 writes the generic computation for a specific i ∈ [N] as

max ⁡ |S|≤K,i∈SR(S;v^) = max ⁡ |S|≤K,i∈S ∑ j∈Srjv^j 1 + ∑ j∈Sv^j. 		(4)

For any α ∈ (0,1], the feasibility check asks whether there exists S ⊆ [N], |S|≤ K, i ∈ S such that

R(S;v^) ≥ α⟺∑ j∈Srjv^j ≥ α + α∑ j∈Sv^j⟺∑ j∈S(rj − α)v^j ≥ α.

Because i must be included, the check is equivalently whether there exists

S′⊆ [N] ∖{i},|S′|≤ K − 1

satisfying

(ri − α)v^i + ∑ j∈S′(rj − α)v^j ≥ α. 		(5)

The nearby prose instructs including in S′ the items with the largest (K − 1) positive values of (rj − α)v^j, and checking (5). A successful check means that revenue level α is attainable; otherwise it is not. These are threshold tests within the computation, not constraints imposed on every offered assortment for every α.

Algorithm 2 supplies the following binary-search rows. Its inputs are {rj}j=1n, {v^j}j=1n, a must-have item i, K, and stopping accuracy δ. Its stated output is an assortment S^ with

|S^|≤ K,i ∈S^,

that maximizes R(S^;v^). Initialize

αℓ = 0,αu = 1,S^ = ∅.

While αu − αℓ ≥ δ, set

αmid ← (αℓ + αu)∕2.

For each j≠i, sort

ψj := (rj − αmid)v^j

in descending order and form

Ψ := {j≠i : ψj ≥ 0}.

The remaining printed rows are

t := ψi + the (K − 1) ψj in Ψ with the largest values; if t ≥ αmid : S^ = {i}∪{the (K − 1) items in Ψ with the largest ψj values},αℓ ← αmid; else : αu ← αmid.

Here t is the scalar used inside Algorithm 2, rather than a customer-arrival index. The loop then repeats its width test.

Printed omissions in Algorithm 2. Line 6 defines ψj only for j≠i, while line 7 uses ψi; the missing definition is not inserted above. Lines 7–8 request (K − 1) items from Ψ without specifying what happens when fewer are available. The prose uses positive values, whereas the pseudocode explicitly uses ψj ≥ 0; the pseudocode’s nonnegative test is retained. The only printed accuracy specification is the stopping test αu − αℓ ≥ δ: no value of δ for the Algorithm 1 invocation, or exact-optimality guarantee at that finite stopping accuracy, is supplied. The output is nevertheless described as a maximizer, and its initialization is the empty set. No tie-breaking, shortage, or initialization repair is added.
