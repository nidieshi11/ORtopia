Retained Core Model

According to the tex formulas and the PDF, the directly solvable compact model is the time-indexed mixed-integer formulation (TI), labeled EC.2a–EC.2p in the e-companion. The Page 9 pattern-based formulation, the Page 10 pricing problem, and the Page 22 connectivity cuts belong to the branch-price-and-cut framework and are omitted here because they rely on implicit route generation rather than an explicit standalone formulation.

Sets and parameters. Let V = {0}∪ N ∪{n′} be the node set, where 0 is the start depot and n′ is the dummy end depot. The customer set is partitioned into pickup customers N+ and delivery customers N−, with N = N+ ∪ N−. Let A be the arc set and K the vehicle set. For each node i, parameter qi denotes collected quantity if qi > 0 and delivered quantity if qi < 0. Parameter dij is routing cost, tij is travel time, Q is vehicle capacity, and T is the maximum route duration. For any subset S ⊆ N, let A(S) = {(i,j) ∈ A : i ∈ S,j ∈ S}.

Decision variables. xijk ∈{0,1} equals 1 if vehicle k traverses arc (i,j). yik is the quantity collected or delivered by vehicle k at customer i. zik is the vehicle load after visiting node i.

Current problem-set network convention. The TI formulation uses a closed directed network. Equation (EC.2c) applies to every node in V , including both depot copies. The supplied instances use A = {(i,j) : i,j ∈ V,i≠j}, including (n′,0) and the other depot arcs. Equations (EC.2a) and (EC.2j) include the supplied costs and times of all selected arcs, including the return arc. The customer quantities satisfy qi ≥ 0 for i ∈ N+ and qi ≤ 0 for i ∈ N−, allowing zero demand, and q0 = qn′ = 0.
