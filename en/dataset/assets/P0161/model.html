Real-time space occupancy

Flying X requires the use of all integer scales t + 1,…,t + rij. The number of aircraft that can be stationed at each node cannot exceed the limit set by capflt. The number of aircraft that can be parked at a node is determined by the initial capacity of that node, plus the number of incoming flights whose arrival times are strictly less than the current scale, minus the number of outgoing flights whose departure times are strictly less than the current scale. This value is specified in [0,1]. The total number of aircraft that can be parked at each node cannot exceed the capacity of that node.
