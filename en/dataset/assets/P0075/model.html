Core Mathematical Model


Multiresource Flexible Job-Shop Scheduling

Source and data definitions. The selected application is the simultaneous-occupation multi-resource flexible job-shop problem, PDF pp.2–3 (printed pp.2323–2324), Sections 2 and 3.1, source equations (1)–(11). Let J be jobs, Ω = ⋃ ⁡ u∈JOu be their operations, and R be actual unary resources. Operation i has requirement groups Gi; group j must receive one resource from Ri,j ⊆ R. The same actual resource cannot serve two groups of the same operation. pi,k ≥ 0 are fixed processing times. PJi are immediate predecessors in a given acyclic precedence graph. All assigned resources are occupied simultaneously for the common operation duration. M is a valid disjunctive constant for the finite scheduling horizon; a feasible serial schedule supplies a makespan upper bound when needed. The independent variables are nonnegative starts τi, durations pi, makespan Cmax ⁡ ≥ 0, assignments Y , resource-use indicators U and pairwise order indicators X, with the binary domains below. The source completion variable is ti = τi + pi; this changes notation, defined by its assignment meaning. The source’s printed equation (3) has a double sum inconsistent with its explanation: we use its explicitly stated per-resource rule, also confirmed by CP constraint (14). The duration epigraph is retained as in source (4); at an optimum durations may be reduced to the largest selected resource processing time without worsening makespan.

For practical Gurobi implementation, we use start-time variables τi, duration variables pi, and auxiliary binary variables Ui,k indicating whether operation i uses resource k. Let Ri = ⋃ ⁡ j∈GiRi,j and let P = {(i,i′) ∈Ω ×Ω : i < i′}. This is equivalent to the paper’s MILP but avoids ambiguous time notation.
