Explicit Auxiliary-Variable Reformulation


Notation and Data

Let I,J,N ∈ ℤ>0 denote, respectively, the number of appointments, patient types, and observed scenarios. Define

[K] := {1,…,K},[a; b] := {a,a + 1,…,b}.

For each patient type j ∈ [J], let Ij ∈ ℤ>0 satisfy

∑ j∈[J]Ij = I.

Let T ∈ ℤ>0 be the planning horizon, let β ∈ (0, 1] be the CVaR parameter, let φ ≥ 0 be the Wasserstein-radius parameter, and let p ≥ 1. Let

τ = (τ1,…,τJ)⊤ ⁡ ∈ ℝJ

be the vector of type-specific delay tolerances. For every l ∈ [I] and n ∈ [N], let

zln = (z l1n,…,z lJn)⊤ ⁡ ∈ ℝJ

be the observed scenario data. For every i ∈ [I], write

xi = (xi1,…,xiJ)⊤ ⁡.

The sequencing-feasible set is

X := {x ∈{0, 1}I×J : ∑ j∈[J]xij = 1∀ ⁡i ∈ [I],∑ i∈[I]xij = Ij∀ ⁡j ∈ [J]} ,

and the appointment-time-feasible set is

Y := {y ∈ ℤI : 0 ≤ y 1 ≤ y2 ≤⋯ ≤ yI ≤ T }.

Decision Variables

The decision variables are x, y, and the continuous auxiliary variables

ηi ∈ ℝ∀ ⁡i ∈{0}∪ [2; I],
γin ∈ ℝ∀ ⁡n ∈ [N],i ∈{0}∪ [2; I].

Auxiliary-Variable Reformulation

For each i ∈ [2; I], the empirical delay-CVaR expression in the decision-dependent empirical model is represented by the auxiliary variables ηi and γin through

(1 −1 β )ηi − yi + 1 Nβ∑ n∈[N]γin,

subject to

γin ≥ y t + ∑ l=ti−1x l⊤ ⁡z ln,∀ ⁡n ∈ [N],i ∈ [2; I],t ∈ [i − 1],
γin ≥ y i,∀ ⁡n ∈ [N],i ∈ [2; I],

and

γin ≥ η i,∀ ⁡n ∈ [N],i ∈ [2; I].

The empirical overtime-CVaR objective is represented by

(1 −1 β )η0 − T + 1 Nβ∑ n∈[N]γ0n,

subject to

γ0n ≥ T,∀ ⁡n ∈ [N],
γ0n ≥ y t + ∑ l=tIx l⊤ ⁡z ln,∀ ⁡n ∈ [N],t ∈ [I],

and

γ0n ≥ η 0,∀ ⁡n ∈ [N].

Optimization Model

The deterministic finite-dimensional reformulation is

min ⁡ x,y,η,γ (1 −1 β )η0 − T + 1 Nβ∑ n∈[N]γ0n (1) s.t. (1 −1 β )ηi − yi + 1 Nβ∑ n∈[N]γin ≤τ⊤ ⁡x i −φ β(i − 1)p−1 p ,∀ ⁡i ∈ [2; I], (2) γin ≥ y t + ∑ l=ti−1x l⊤ ⁡z ln, ∀ ⁡n ∈ [N],i ∈ [2; I],t ∈ [i − 1], (3) γin ≥ y i, ∀ ⁡n ∈ [N],i ∈ [2; I], (4) γin ≥ η i, ∀ ⁡n ∈ [N],i ∈ [2; I] ∪{0}, (5) γ0n ≥ T, ∀ ⁡n ∈ [N], (6) γ0n ≥ y t + ∑ l=tIx l⊤ ⁡z ln, ∀ ⁡n ∈ [N],t ∈ [I], (7) x ∈X,y ∈Y . (8)

All products involving x and the scenario vectors zln, as well as τ⊤ ⁡x i, are affine after expansion because the scenario data and tolerance vector are fixed. The auxiliary variables η,γ ∈ ℝ satisfy the displayed constraints.
