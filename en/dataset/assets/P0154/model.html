Entering boundaries and solving the problem

The bounded time domain can take values like 0 ≤ t ≤∑ ⁡ sns + (|K| + 1)hmax and M. The upper limit is determined by adding up all the required running/safety intervals. This value is used in the aforementioned logical expressions. The code first determines the sequence of trains that satisfy the type successor constraints, then constructs curves with fixed safety intervals and precise speeds. The candidate configurations involve speeds that start and end at 0, with acceleration and deceleration periods of 20 seconds each. The speeds and acceleration/deceleration times in the model are determined based on their respective variable ranges. All running times, distance equations, speed limits, constraints related to successor relationships, and physical safety requirements are checked separately. Each instance has a total of 3600 seconds to complete the task. The system returns a complete set of feasible moments, speed curves, and feasible target values.
