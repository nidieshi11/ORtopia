Cut-Based Maintenance Master Formulation


1 Sets and input data

Let G′ and L′ be the finite sets of maintained generators and transmission lines, with distinct component identifiers, and let H′ = G′∪ L′. Let T = {1,…,N}, where N ≥ 1, be the planning periods and let T¯ = {1,…,N + 1}. Assignment to period N + 1 means that no maintenance is scheduled within the planning horizon. Define the coordinate set I = H′×T¯ and its size d = |H′|(N + 1). Let K be the finite scenario set.

The scenario weights are πk ≥ 0, with ∑ ⁡ k∈Kπk = 1. For each k ∈ K, the maintenance-cost vector is ck = (ck,ht)(h,t)∈I ∈ ℝd, and Lk ∈ ℝ is the supplied valid scenario recourse lower bound. All vectors indexed by I use the same coordinate ordering.

1.1 Exact reliability classification

Define the finite collection of scheduling sets

𝒮 = {C ⊆I :|C ∩ ({h}×T¯)| = 1for every h ∈ H′}.

For C ∈ 𝒮 , let tC(h) denote its unique selected period for component h. The input ℱ ⊆ 𝒮 is the complete exact list of reliability-infeasible scheduling sets: it contains precisely those schedules whose source-defined joint reliability probability is strictly below 1 − α, where α ∈ [0,1] is the risk tolerance. Equality to 1 − α is feasible. This classification uses the independent component failure indicators and the independent generator and line Poisson-binomial sums, including components not maintained. For a component assigned to period N + 1, the failure probability is evaluated at N, as it is for a component not maintained. The complete reliability classification is supplied as model data.

1.2 Accumulated reliability cuts

Let JC index the supplied finite accumulated reliability-cut pool. For each j ∈ JC, supply a cover Cj ∈ ℱ and the row support Dj ⊆I used by that retained cut. Its support is either the original cover Cj or its source-defined extended cover

E(Cj) = ⋃ h∈H′{(h,t) : tC(h) ≤ t ≤ N + 1},tC(h) = tCj(h).

The support Dj is fixed input data. The pool may be empty.

1.3 Accumulated scenario-level optimality cuts

Let JΘ index the supplied finite pool of scenario-level optimality cuts defining the selected master instance. Supply coefficient arrays

AΘ ∈ ℝ|JΘ|×d,BΘ ∈ ℝ|JΘ|×|K|,bΘ ∈ ℝ|JΘ|.

Row r ∈ JΘ is the retained affine inequality written in the orientation

∑ k∈KBrkΘ𝜃k ≥b rΘ + ∑ (h,t)∈IAr,htΘv ht.

These arrays are the exact coefficients of the retained cuts, including their fixed anchor schedules, recourse values, lower bounds, and period subsets after algebraic expansion. In particular, an aggregate cut with the unweighted left-hand side ∑ ⁡ k∈K𝜃k has BrkΘ = 1 for every k. The supplied cut pool may be empty or partial and defines the recourse approximation used by the master problem.

2 Decision variables

For each (h,t) ∈I, vht is binary and equals one when component h is assigned to maintenance period t. For each k ∈ K, 𝜃k is a continuous scenario recourse-cost master variable. Its domain is 𝜃k ∈ [Lk,+∞).

Consequently, the formulation represents the selected master instance, without strengthening a partial optimality-cut pool to the full recourse epigraph.
