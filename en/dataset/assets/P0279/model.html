Public transportation freight transportation strategy planning: Path flow model

This document uses the path-based representation for describing the selected models. Site flows and line status flows are represented separately, and they are not combined into a single model along with the path-based representation. The symbols used in the representation are based on pages 5, 6, and 8 of the original paper. F,L,S,K represents teams, lines, sites, and products; f(ℓ) represents the team to which the line belongs; Lf = {ℓ : f(ℓ) = f} and Ls = {ℓ : s ∈ Sℓ} represent other relevant elements. For each directed line, Sℓin occurs before Sℓout on the path. Neither of these two elements intersects with each other. Sℓkin = Sℓin ∩ Skin and Sℓkout = Sℓout ∩ Skout represent additional elements related to the line. W = {(k,ℓ,s,t) : s ∈ Sℓkin,t ∈ Sℓkout} is defined as such. The variable xs,yℓ,zf ranges from 0 to 1. wkℓst ∈ ℤ≥0 is only defined in relation to W. Values outside the summation range are treated as 0.

The completed instance retains the order of stations along the route, as well as information regarding requirements, capacity, and budget. For those routes where certain stations are not covered, each route’s first half of stations will be designated as “loading stations”, while the second half will be designated as “unloading stations”. This provides clear operational data for reference. Station roles are defined based on the above data. It is prohibited to load or unload goods at the same station, or to transport goods in reverse order. The maximum coverage model allows for some goods to not be covered at all.
