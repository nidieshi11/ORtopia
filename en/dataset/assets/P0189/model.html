Collections, parameters, and variables

K Refer to the truck group. Each group is equipped with drones from the set of IDs D. O = {0,1,…,o,o + 1} Represent roads that are accessible to trucks. Here, 0,o + 1 refers to the departure/return copies within the same warehouse. O− = O ∖{o + 1}, O+ = O ∖{0}, O0 = O ∖{0,o + 1}… C Refer to customers who only receive services provided by drones. N = O ∪ C All arcs are excluded from loops; undefined/non-existent arcs have variable values set to zero. tijK Represents the travel time on roads. ticD = tciD Represents the flight time between road nodes and customers. sG,sK,sD,sT ≥ 0 Represents costs associated with driving, flying, and delayed arrivals. qc Represents demand. mK Represents truck capacity. ec Represents the expected latest arrival time for customers. M Is a constant that has been verified to be sufficiently large relative to the time limit. Under the assumptions outlined in this document, the batteries are sufficient to support one-way flights for each customer. Battery charging times are ignored; this model does not optimize battery levels separately.

αijk represents the arc of the truck; βijdk refers to the arc of the drone (used for routes where the vehicle carries the drone along with it). 𝜀k indicates that the truck group is enabled. δik ≥ 0 represents the synchronization moment of the group at a specific node. μik,φidk is the integer indicating the order of access. τck1+,τck1−≥ 0 represents the amount of linearization for late/early arrivals. For groups that aren’t used, 0 → o + 1 represents a virtual arc with zero time consumption and zero cost.
