Problem: **Multi-vehicle Dial-a-Ride Problem with Interchange (DARPi)**. This problem belongs to the category of **Vehicle Routing Problems (VRP)**. It combines elements of Pickup and Delivery Problems with features related to transfer points. The problem is a **Mixed Integer Linear Programming (MILP)** problem; the original non-linear problem is transformed into a MILP form through linearization. DARPi is a **NP-hard** combinatorial optimization problem, involving various constraints such as time windows, capacity limits, and travel times.

The complete definition of perceived time

On page 10 of the source text, it is clearly stated that option 41 replaces option 23–24. Therefore, ri is defined solely by ri = p~n+i −p~i, while ri ≤ L determines the perceived riding time. The actual time u~ is used only for independent diagnostics purposes. Link relaxation is denoted as σu. The perceived time is calculated using a different method, denoted as σp; these two methods should not be used interchangeably.

Clear conventions for marking questions in this set of questions

Both of the two time-windowed arc selections belong to the same vehicle, namely k. According to the definitions given in the third subscript, these can be denoted as xjik and xijk, and need to be calculated separately for each vehicle. The coefficient for the first arc remains unchanged, being tij – that is, the time interval from the current point i to the previous point j. The coefficient for the second arc remains the original plus sign. The passenger demand at the four boundary points is defined as qo1 = qo2 = qo3 = qo4 = 0; the demand from customers is provided by individual instances. Here, A,P,D,K is an equivalent notation for A,P,D,K.
