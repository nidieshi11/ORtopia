\section*{Problem: **Multi-vehicle Dial-a-Ride Problem with Interchange (DARPi)**. This problem belongs to the category of **Vehicle Routing Problems (VRP)**. It combines elements of Pickup and Delivery Problems with features related to transfer points. The problem is a **Mixed Integer Linear Programming (MILP)** problem; the original non-linear problem is transformed into a MILP form through linearization. DARPi is a **NP-hard** combinatorial optimization problem, involving various constraints such as time windows, capacity limits, and travel times.}

\section*{The complete definition of perceived time}

Therefore, $r_i$ is defined solely by $r_i=\tilde p_{n+i}-\tilde p_i$, while $r_i\le L$ determines the perceived riding time. The actual time $\tilde u$ is used only for independent diagnostics purposes. Link relaxation is denoted as $\sigma^u$. The perceived time is calculated using a different method, denoted as $\sigma^p$; these two methods should not be used interchangeably.
\[

The legal journey paths are indicated for each instance: the first journey starts at $o_1$ and ends at $o_2$; the second journey starts at $o_3$ and ends at $o_4$. Both of the two time-windowed arc selections belong to the same vehicle, namely $k$. According to the definitions given in the third subscript, these can be denoted as $x_{ji}^k$ and $x_{ij}^k$, and need to be calculated separately for each vehicle. The coefficient for the first arc remains unchanged, being $t_{ij}$ – that is, the time interval from the current point $i$ to the previous point $j$. The coefficient for the second arc remains the original plus sign. The passenger demand at the four boundary points is defined as $q_{o_1}=q_{o_2}=q_{o_3}=q_{o_4}=0$; the demand from customers is provided by individual instances. Here, $A,P,D,K$ is an equivalent notation for $\mathcal A,\mathcal P,\mathcal D,\mathcal K$.
