P49: Enhanced Linear Integer Model for Quantum Bit Configurations with Noise Perception

Source and scope According to pages 1, 2, 3, 4, 10, 11, 12, 13, 14, 15, and 16 of the original paper’s PDF file, specifically section 3, equations (1b)–(1k) and (12)–(17). Crosstalk effects are modeled using the same type of McCormick linearization as described in equation (2).

Collections, parameters, and variables

Q represents a collection of logical quantum bits; H = (V,AH) represents a connected directed graph of hardware components. |V |≥|Q| indicates that the set of arcs is symmetric. N ∈ ℤ++ denotes the number of circuit layers. Lt ⊆ Q × Q refers to the dual-bit gates in the tth layer, where no two gates share the same logical quantum bit. dH(i,j) represents the shortest path distance in the hardware graph. λ ∈ [0,1] indicates a given trade-off coefficient. Ei ≥ 0 represents the cost associated with single-bit gates/reading noise. Ei,j ≥ 0 represents the noise cost associated with directed dual-bit gates. These costs must be specified for each hardware component used in the system. Let NH(i) = {j : (i,j) ∈ AH} and N((i,j)) = (NH(i) ∖{j}) ∪ (NH(j) ∖{i}) represent certain parameters. Given a measured error rate ratio of r(i,j)k ≥ 0, the crosstalk coefficient is E(i,j),k = max ⁡ {0,(r(i,j)k − 1)Ek}. The variable wq,it indicates that the logical bit q in layer t occupies a hardware bit i. xq,i,jt indicates that q is transferred from i to j between adjacent layers. z(p,q),(i,j)t indicates that the logical gate (p,q) is executed via the hardware arc (i,j). uq,(r,s),(i,j),kt is a linearization variable of wq,ktz(r,s),(i,j)t. The complete index domain of u is 1 ≤ t ≤ N,(r,s) ∈ Lt,(i,j) ∈ AH,k ∈ N((i,j)),q ∈ Q. The initial layout is optimized automatically by the model, and all layers use the same hardware subgraphs. The following numbers, such as 1a, are used in this documentation. The sources of these numbers are mentioned in the original text (1), (12)–(17).
