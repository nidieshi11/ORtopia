Piecewise McCormick Reformulation of a Bounded QCQP


Notation and Data

Let [s] := {1,…,s}, and let n,m,d ∈ ℤ+ with d ≥ 1. Let

B ⊆{(i,j) ∈ [n]2 : i < j},Q ⊆ [n]

be, respectively, the sets of bilinear and univariate quadratic terms. Define

NC :={i ∈ [n] : ∃ ⁡j ∈ [n] such that (i,j) ∈B or (j,i) ∈B} ∪Q.

For each i ∈NC, let the fixed breakpoint vector be

Pi = (Pi1,…,Pi,d+2),0 = Pi1 ≤ Pi2 ≤⋯ ≤ Pi,d+1 ≤ Pi,d+2 = 1.

Let Q0,Qi ∈ 𝕊n and r0,ri ∈ ℝn for i ∈ [m], and let bi ∈ ℝ for i ∈ [m].

Decision Variables

The decision variables are

xi ∈ ℝ(i ∈ [n]),Wij ∈ ℝ(1 ≤ i ≤ j ≤ n),
Y iℓ ∈{0,1}(i ∈NC,ℓ ∈ [d + 1]),
Λkℓij ≥ 0((i,j) ∈B,k,ℓ ∈ [d + 2]),Λ ℓk ≥ 0(k ∈Q,ℓ ∈ [d + 2]).

For notational purposes, set Wji := Wij whenever j < i.

Piecewise McCormick Reformulation

min ⁡ ∑ i=1nr i0x i + ∑ i=1nQ ii0W ii + 2∑ 1≤i<j≤nQij0W ij (1)

subject to

0 ≤ xi ≤ 1, i ∈ [n], (2) ∑ j=1nr jix j + ∑ k=1nQ kkiW kk + 2∑ 1≤k<ℓ≤nQkℓiW kℓ ≤ bi, i ∈ [m]. (3)

For every (i,j) ∈B, impose

xi = ∑ k=1d+2 ∑ ℓ=1d+2Λ kℓijP iℓ, (4) xj = ∑ k=1d+2 ∑ ℓ=1d+2Λ kℓijP jk, (5) Wij = ∑ k=1d+2 ∑ ℓ=1d+2Λ kℓijP iℓPjk, (6) ∑ k=1d+2 ∑ ℓ=1d+2Λ kℓij = 1, (7) ∑ k=1d+2Λ k1ij ≤ Y i1, (8) ∑ k=1d+2Λ k,d+2ij ≤ Y i,d+1, (9) ∑ k=1d+2Λ k,ℓ+1ij ≤ Y iℓ + Y i,ℓ+1, ℓ ∈ [d], (10) ∑ ℓ=1d+2Λ 1ℓij ≤ Y j1, (11) ∑ ℓ=1d+2Λ d+2,ℓij ≤ Y j,d+1, (12) ∑ ℓ=1d+2Λ k+1,ℓij ≤ Y jk + Y j,k+1, k ∈ [d]. (13)

For every k ∈Q, impose

xk = ∑ ℓ=1d+2Λ ℓkP kℓ, (14) Wkk ≤∑ ℓ=1d+2Λ ℓk(P kℓ)2, (15) ∑ ℓ=1d+1Y kℓPkℓ ≤ xk ≤∑ ℓ=1d+1Y kℓPk,ℓ+1, (16) ∑ ℓ=1d+1Y kℓ = 1, (17) ∑ ℓ=1d+2Λ ℓk = 1, (18) Wkk ≥ xk2, (19) Λ1k ≤ Y k1, (20) Λd+2k ≤ Y k,d+1, (21) Λℓ+1k ≤ Y kℓ + Y k,ℓ+1, ℓ ∈ [d]. (22)

The shared partition-selection variables satisfy

∑ ℓ=1d+1Y iℓ = 1, i ∈NC, (23) Y iℓ ∈{0,1}, i ∈NC,ℓ ∈ [d + 1]. (24)

The auxiliary variables satisfy

Λkℓij ≥ 0, (i,j) ∈B,k,ℓ ∈ [d + 2], (25) Λℓk ≥ 0, k ∈Q,ℓ ∈ [d + 2]. (26)
