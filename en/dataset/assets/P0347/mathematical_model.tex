\section*{Robot and truck-based package distribution model}

This model involves the assignment of tasks to robotic vehicles and trucks, without considering path optimization. $P,Z,R_z$ represents packages, regions, and sets of robots within a region; $z_p$ indicates the region to which a package belongs. $c_T,c_R$ represents the cost per package delivery. $f_T,f_R$ represents the fixed costs associated with using individual robots or vehicles (see Table 4 on page 10 of the original paper, $fc_T,fc_R$). $Q_T,Q_R$ represents the capacity for handling a certain number of packages. $D$ represents the distance threshold. The original model measured the workload required for truck deliveries based on the number of robots available. This capacity is still used in the new model. $B_p=\mathbf1_{\{w_p>m_W\ \mathrm{or}\ m_p>m_M\}}$ is calculated based on explicit weight and size thresholds.
\begin{align*}
\min\quad &c_T\sum_px^T_p+c_R\sum_{p,z,r}x^R_{pzr}
+f_Ty^T+(f_R+c_T)\sum_{z,r}z^R_{zr}\\
\text{s.t.}\quad&
x^T_p+\sum_{r\in R_{z_p}}x^R_{p,z_p,r}=1&&(p\in P),\\
&x^T_p=1&&(p:B_p=1),\\
&x^R_{pzr}=0&&(z\ne z_p),\\
&\sum_{p:z_p=z}x^R_{pzr}\le Q_Rz^R_{zr}&&(z\in Z,r\in R_z),\\
&\sum_px^T_p+\sum_{z,r}z^R_{zr}\le Q_Ty^T,\\
&x^R_{pzr}+x^R_{qzr}\le1&&(z,r,p,q:d_{pq}>D),\\
&x^T,x^R,z^R\in\{0,1\},\quad y^T\in\mathbb Z_{\ge1}.
\end{align*}
Package dimensions use a common scale (centimeters in these instances), weights are in kilograms, and distances use the common unit of the input matrix. Missing diagonal distances are filled with 0. The added weights and dimensions preserve the original oversized-package classification and are explicitly synthetic values supplied as data. The original $c_F=200$ is retained as the special input case in which both fixed charges are 200. Setting variables outside their region to 0 makes the regional service limits explicit. This does not affect the optimal objective value in these instances, where all delivery unit costs are positive.
