Selection-and-routing model

Let M, Π, L, and Q be finite sets of mines, ports, granularities, and attributes. The planning periods are 1,…,T. Mine m has Nm fixed candidate schedules s→m,j, indexed by j = 1,…,Nm; Nπ,l is the set of products of granularity l at port π. The given integer-valued routing-window endpoints satisfy 1 ≤ f(t) ≤ t and t′≤ g(t′) ≤ T.

The scalar parameters are β1,β2,TR, the candidate values Pjm, port capacities Cπt, product quality bounds Lπ,l,n,qt and Uπ,l,n,qt, and attribute-deviation coefficients λq+. For each fixed candidate schedule, τlm(s→m,j,t′) is its production and vl,qm,t′ (s→m,j) is its composition value.

Define the routing index set

W = {(t,t′) : 1 ≤ t′≤ t ≤ T,f(t) ≤ t′}∪{(t,t′) : 1 ≤ t′≤ t ≤ T,t ≤ g(t′)}.

The variables are binary schedule selections sm,j, nonnegative routing quantities rπ,n,tm,l,j,t′ for (t,t′) ∈W, unrestricted affine-expression variables zπ,l,n,q+,t,zπ,l,n,q−,t, and nonnegative positive-part variables dπ,l,n,q+,t,dπ,l,n,q−,t. The z and d variables are indexed by π ∈Π, l ∈L, n ∈ Nπ,l, q ∈Q, and t = 1,…,T.
