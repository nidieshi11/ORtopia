\section*{AMR works together with sorters to select the appropriate M0 integration models.}

\paragraph{Source} Pages 5–9 of the PDF document, sections 3–4. Equations M0(4.1)–(4.42) remain intact. Only the main model is integrated directly; the SRMP and the other set of position assignment algorithms are not included in the integration process.
\subsection*{Collections and parameters}
$I,R,P,S,U$ Represents orders, robots, pickers, shelves, and SKU collections respectively. $o(s),e(s)$ Represents the virtual start and end points of each route. $o(r),e(r)$ Represents the virtual end points of the robot service sequences on shelves. These symbols are index labels. All path arcs do not contain self-loops. $q^I$ Represents the maximum number of orders per robot. $n^O_{iu}$ Represents order requirements. $n^S_{su}$ Represents shelf inventory levels. $w^U_u,v^U_u$ Represents the weight/volume per SKU unit. $w^R,v^R$ Represents the maximum capacity of a robot. $t^R_{ss^{\prime}},t^P_{ss^{\prime}}$ Represents the walking time between robots/pickers and shelves (including endpoints). $t^{R0}_{rs},t^{P0}_{ps}$ Represents the time required to reach the first station from the current position. $h$ Represents the processing time for each type of SKU being picked: explicitly mentioned in sections (4.27), (4.29), and (4.31). $h\sum_u\mu_{rsu}$ Represents the amount of time required to perform operations at the listed shelves. $\dot M,\ddot M,M^{27}_{ss^{\prime}},M^{29}_{ss^{\prime}},M^{30}_s,M^{31}$ Represents a sufficiently large upper limit for effective operations.
\subsection*{Variables and their meanings}
$\alpha$ indicates the order being assigned to a robot/fulfillment worker for processing. $\beta,\gamma$ indicates whether the SKU has been picked from the shelves. $\#_{rsu}$ represents the quantity of items to be picked. $\mu$ indicates whether the SKU has been picked at all. $\delta,\varepsilon$ refers to the path taken by the robot/fulfillment worker during picking. $\sigma$ indicates the order in which robots pick items from the same shelf. Numbers with a wave symbol indicate the corresponding integer sequence. $\epsilon,\theta$ represents the arrival time. $\rho$ indicates the start time for picking items.

\subsection*{The only goal and all the constraints}
\[\min\ \max_{r\in R}\epsilon_{r,e(s)}.\tag{4.1}\]
\[\begin{aligned}&\text{Order allocation and robot path planning:}\end{aligned}\]
\[\begin{aligned}& \sum_{r \in R} \alpha_{i, r} = 1 \quad \forall i \in I\end{aligned}\]

The order value of the route starting point is fixed at zero; the virtual end point can be set to “actual visits plus one”. An empty route refers to a virtual starting point directly leading to the end point. When the actual shelves are not visited, the related arrival and service times are fixed to zero according to the above formula. All quantity domains are continuous and non-negative as stated in (4.38). $\mathbb Z^+$ is represented as a non-negative integer in this arrangement. No additional integer restrictions on picking are added, as not present in the original text. The symmetric breaking method from (4.35)–(4.36) applies to homogeneous resources where the initial state can be exchanged.
