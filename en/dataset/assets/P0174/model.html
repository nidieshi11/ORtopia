The order value of the route starting point is fixed at zero; the virtual end point can be set to “actual visits plus one”. An empty route refers to a virtual starting point directly leading to the end point. When the actual shelves are not visited, the related arrival and service times are fixed to zero according to the above formula. All quantity domains are continuous and non-negative as stated in (4.38). ℤ+ is represented as a non-negative integer in this arrangement. No additional integer restrictions on picking are added, as not present in the original text. The symmetric breaking method from (4.35)–(4.36) applies to homogeneous resources where the initial state can be exchanged.
