\section*{The current issue relates to the input boundaries.}
The current solution involves determining the locations of charging stations, assigning limited number of plugs to each vehicle, and managing hourly usage of parking spaces. Time, energy consumption, and costs are all specified by the instances, thereby forming a deterministic scheduling model. According to Table 1 on page 6 of the paper, the parking lot numbers $C'\subseteq C$, $c$, and charging station $c$ use the same numbering system. $s_c,f_c$ represents both the departure and return nodes. In existing instances, $C'=C$ is used as the parking lot number for each station. Charging requirements during returns are denoted as $Y_{ic}\ge X^k_{if_c}$ under this common numbering system. $T$ represents the set of all service trips. The bitwise sum of the usage times in equation (21) is calculated using $T$. The residual variable $H$, which is not involved in this model, has been removed from the description.
