Single station, single period rolling bus scheduling using RHMILP algorithm

Source and scope Pages 10–12 of the PDF document, section 3.2: RHMILP(33)–(55). This is a complete scheduling model for a terminal station and a rolling time period. The model takes into account the environmental conditions of other terminal stations, as well as the empty-run targets specified by DRL.

Combining with known parameters

B Represents scheduled bus routes. K Refers to the route at that terminal station. H = {1,…,Hmax ⁡ } Indicates the order in which buses depart. N = {1,…,Hmax ⁡ } Represents candidates for the number of buses to be dispatched. YI = {1,…,m} Represents equal-length charging intervals. v > 0 Represents the duration of the current segment. Sk,ak Representing the service frequency and the target number of vehicles available for service. λb Represents the known arrival time at the station. βb ∈ [0,100] Represents the known percentage of SOC at the station/initial state. μks,μkd Represents the required operating volume for both service and vehicle movement. ζ Represents the conversion to SOC consumption. τ ≥ 0 Represents the safety margin for service operations. W Represents the SOC charging rate per unit time. |Ψ| Represents the number of charging points available. Cs,Cd,ρ1,ρ2 ≥ 0 Represents the weight of deviation penalties/rewards. M Represents a valid large constant that covers all time and SOC scenarios. The discrete charging zones must be fixed:

γiC = (i − 1)v∕m,λ iC = iv∕m,i = 1,…,m.

These two symbols indicate the fixed start and end points of the discrete time intervals.

Variables

Ibhk represents the departure time of vehicles. κhk indicates the service shift (relative to the empty driving hours). NnkB refers to the selection of the number of shifts. νbi denotes the duration during which the vehicle is occupied for charging. γH,γB specifies the departure time for each shift/vehicle. ϕb indicates the additional SOC available for charging. Nk,Pk shows the total number of departures and the interval between each shift. Gks,Gkd,Gb reflects any deviations and the maximum amount of energy that can be lost during charging. Pk uses equations (41) and (55) to determine continuous, non-negative intervals between shifts. The value Nk is a natural number resulting from binary choices.
