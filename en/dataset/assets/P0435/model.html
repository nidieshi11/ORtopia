Alpha–Beta–Gamma Graph Formulation


Notation and data

Let G = (V,E) be an undirected graph, where V is the vertex set and E ⊆{{i,j} : i,j ∈ V,i≠j} is the edge set. Let C be the set of colors, and let V c ⊆ V denote the set of vertices having color c ∈ C. For each i ∈ V , let

N(i) = {j ∈ V : {i,j}∈ E}

denote the neighborhood of i. For each U ⊆ V , define the induced edge set and cut set by

E(U) = {{i,j}∈ E : i ∈ U,j ∈ U},δ(U) = {{i,j}∈ E : |{i,j}∩ U| = 1}.

For every W ⊆ V , let tW be the given edge-connectivity parameter of the induced graph G[W]. The displayed constraints involving 1∕|N(i)| and 1∕|V c| are defined for indices with |N(i)| > 0 and |V c| > 0.
