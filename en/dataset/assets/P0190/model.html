Indexing, input, and variable definitions

The entrance lane is designated as i. The lanes numbered from right to left are j. Vehicles indexed by their positions are designated as k. Vehicles grouped together are Ω = ΩCAV ∪ΩOV . Only CAV-controlled vehicles are included in this category. f(j) represents the mapping between lanes and signal phases (using the mapping appropriate for the entrance lane). The eight-phase system is represented by ϕ1,…,ϕ8. This system follows the NEMA dual-barrier sequence. Iϕ indicates that the current phase is green; gϕp,tϕl indicates that the green light has been passed and time has been lost. ϕg refers to the current green light in the same barrier. ϕp represents the phases that follow the current phase and precede the target phase, as described in equation (7). gmin ⁡ ,gmax ⁡ represents the maximum duration allowed for each phase.

The vehicle inputs dstop,P,v,vlat,dlat which include distance from the stop line, position along the lane, current speed, lateral speed, and lateral deviation. vl = vl represents the speed limit, vt is the passing speed, amax ⁡ ,dmax ⁡ > 0 are the speed increment/decrement limits, vlc is the minimum speed for lane changing, and vavgCAV ,vavgOV > 0 is the average speed near the entrance. dacc,ddec indicates the acceleration/deceleration distance calculated based on the given driving conditions. dv,dg,theadway,dh includes vehicle length, minimum spacing, expected headway, and release headway. CNLi indicates areas where lane changing is prohibited, ddis is the specified distance for queue clearing, and ef(j) represents the red light indication when entering the area. Ijlm,Ijrm identifies the leftmost/rightmost lane. Kijkfront(ℓ) represents the vehicles ahead of the vehicle in question on the candidate lane ℓ. kf,kfl indicates the immediate vehicles ahead and behind on the candidate lane (only neighboring vehicles apply corresponding safety measures). GAPij is the lane spacing. KqjL,KqjR represents the group of vehicles that can enter the gap from adjacent left and right lanes. Isafety,Ispeed,INCG includes the conditions for lane changing as pre-evaluated according to rules from (17)–(23) and page 8. Lane changes conflicting with each other are prioritized based on the one closer to the stop line. M represents the valid upper bounds for various condition expressions.

Jijktarget represents a set of absolute lane numbers that are compatible with the vehicle’s subsequent path. J^ijk represents a set of lanes that can be maintained or moved one step closer to the target direction. Action j′ = 0,1,2 corresponds to ℓijk(j′) = j + 1,j,j − 1. The action of leaving the road is defined as zero. According to conditions (10), the value 1 is taken if the conditions are met, otherwise 0 is used. To avoid direct comparison between the action numbers and absolute lane numbers, an explicit mapping using ℓ is employed. fl,fr Returns 1 if conditions (11)–(12) are met; otherwise, 0 is returned.

Decision variables ta,d,r,g,𝜃,C,tdis ≥ 0 represent arrival time, delay, remaining red lights, remaining green lights, phase duration, cycle duration, and queue release time. δ0,1,2,α,β ∈{0,1} refers to lane change actions and pass marks for the current cycle. nr,c,l represents non-negative integer queue counts, with “green” or “red” indicating the direction of the queue movement. jnew refers to the derived lanes defined by (16). Variables t in equations (47)–(49) represent the ta values of the preceding vehicle.
