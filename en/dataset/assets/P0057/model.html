Core Mathematical Model


Fuel-Constrained Unit Commitment

To make the model directly implementable in Gurobi, we use explicit initial conditions (y0,x0) and the exact period-specific piecewise-linear production-cost curve supplied in the instance data. In particular, for each period t, the solver reads ordered breakpoint-value pairs (χtm,ϕtm)m∈Mt from f_t.breakpoints_MW and f_t.values, and enforces the resulting polyline with Gurobi’s addGenConstrPWL. When these data define a convex curve, this is equivalent to a supporting-line epigraph; otherwise the implemented model follows the nonconvex polyline itself. The repository implementation also exposes a period-length parameter Δt = period_length; in the current solver, Δt scales only the production-cost term, while the revenue term ξtxt and the fuel budget Q remain unscaled.
