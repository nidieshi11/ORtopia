Core model: first-mile ridesharing with service-quality preferences

Source: Sections 3.1–3.3, PDF pp.4–7, Table 2 and (1)–(19). Only the complete original arc-based MILP is retained.

Data. K is the heterogeneous vehicle set. Requests R = RG ∪˙ RD are general and high-priority groups. Vehicle k starts at ready location gk and all passengers go to station 0. Define

Ak = {(gk,j) : j ∈ R}∪{(i,j) : i ∈ R,j ∈ R ∪{0},i≠j}.

All other arcs, including self-loops, outgoing station arcs and arcs to ready locations, are absent. Vehicle capacity, ready time and latest station arrival are qk,rk,Lk. For request i, pi is its number of riders, si boarding/service time, ei earliest pickup, ai latest station arrival, ϖi acceptable number of co-riders excluding its own party, and ui acceptable ride time. dij is distance, v > 0 speed (time units must agree), c ≥ 0 distance cost, and f ≥ 0 vehicle fixed cost. αg,αd penalize excess ride time and ςg,ςd excess co-riders; high-priority coefficients are larger. The source uses T = max ⁡ iai and P = ∑ ⁡ ipi in the following deactivation terms. Its intended time horizon and distances must make these constants valid.

Variables and derived assignment. xijk,yk ∈{0,1} select arcs and vehicles. Let bik := ∑ ⁡ j∈R∪{0}∖{i}xijk (an expression, fixed expression). dtk ≥ 0 is departure time, tik ≥ 0 pickup time (i ∈ R), and t0k ≥ 0 station arrival. ϱk ∈ ℤ+ is total carried riders; ζi ∈ ℤ+ excess co-riders; ξi,zi ≥ 0 ride-time epigraph and excess ride-time penalty quantity. Here ℤ+ includes zero.

The hard seat capacity is never softened. Co-rider and ride-time preferences are soft, but the latest station arrival remains hard for every assigned request. With nonnegative penalty coefficients the epigraph variables attain their relevant positive-part quantities at an optimal solution.
