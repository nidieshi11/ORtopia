\section*{P7: Complete path representation of indivisible fixed-cost network flows (Path-FCNF)}
\paragraph{Source and scope}According to sections 3, objectives of paths, and equations (7)–(10) on pages 1, 3, 4, and 5 of the original paper PDF file, it refers to the binary path domain.

\subsection*{Collections and parameters}
Let $D=(N,A)$ be the directed network and $K$ be the set of commodities. Commodity $k$ has an origin $s(k)$, a destination $t(k)$, and demand $d_k>0$. The unit transportation cost, activation fee, and capacity for the arc $(i,j)$ are respectively $c_{ij}\ge0,f_{ij}\ge0,u_{ij}\ge0$. $P(k)$ is the set of all feasible origin-to-destination paths for commodity $k$. $A(p)$ is the set of arcs used by path $p$. In the unsplittable-demand case considered here, all demand of each commodity is routed on a single path.
\subsection*{Variables and the complete model}
$x_p^k$ indicates that the product $k$ should be used for the path $p$. $y_{ij}$ indicates that the arc function should be enabled for $(i,j)$.
\begin{align}
\min\quad &\sum_{k\in K}\sum_{p\in P(k)}d_k\Bigl(\sum_{(i,j)\in A(p)}c_{ij}\Bigr)x_p^k+\sum_{(i,j)\in A}f_{ij}y_{ij},\label{obj}\\
\text{s.t.}\quad &\sum_{p\in P(k)}x_p^k=1 &&k\in K,\tag{7}\\
&\sum_{k\in K}\sum_{p\in P(k):(i,j)\in A(p)}d_kx_p^k\le u_{ij}y_{ij} &&(i,j)\in A,\tag{8}\\
&y_{ij}\in\{0,1\} &&(i,j)\in A,\tag{9}\\
&\sum_{p\in P(k):(i,j)\in A(p)}x_p^k\le y_{ij} &&k\in K,(i,j)\in A,\tag{10}\\
&x_p^k\in\{0,1\} &&k\in K,p\in P(k).\tag{D}
\end{align}
Equation (10) links path selection with the activation of arcs. When using the subset of paths $\bar P(k)\subsetneq P(k)$, the feasible region consists of all paths within this subset.
