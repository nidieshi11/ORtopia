Random systems and parameters

The driver area type collection is N = {1,…,N}, the passenger type collection is J = {1,…,J}, and the duration is T > 0. The driver arrival rate λi(t), passenger arrival rate μj(t), and the rate at which unmatched drivers leave 𝜃i(t) are all known non-negative functions. Λi(t) = ∫ 0tλi(s)ds and Γj(t) = ∫ 0tμj(s)ds are also involved. Ai,Ri,Ej represents a Poisson process where each unit time follows independent and mutually exclusive patterns, affecting the arrival of drivers, the departure of drivers, and the arrival of passengers respectively. Qi(0) ∈ ℤ+ represents the initial number of drivers following a given distribution, which is independent of other random variables. The boundaries of the specified time periods 0 = τ0 < τ1 < ⋯ tend to infinity. tij(m) ≥ 0 represents the time during which drivers can pick up passengers during the period m. ajk(m) ≥ 0 represents the maximum waiting time that the kth passenger of type j can endure during the period m. This waiting time follows a given distribution, and is independent of other random variables, as determined by k. wij ≥ 0 represents the weight used to determine the matching between drivers of type i and passengers of type j. All random variables are defined within the same probability space (Ω,F, ℙ). The moment of passenger arrival is νj(k) = inf ⁡ {t : Ej(Γj(t)) = k}.
