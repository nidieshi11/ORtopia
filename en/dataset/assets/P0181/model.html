Finite-Sample Stochastic Scheduling Deterministic Equivalent


Sets and parameters

Let I, A, and R be finite sets of surgeries, anesthesiologists, and operating rooms, respectively. Let Ns ∈ ℤ>0 and N = {1,…,Ns} be the sample count and sample index set. Write I≠2 = {(i,j) ∈ I2 : i≠j} and I≠3 = {(i,j,h) ∈ I3 : i,j,h pairwise distinct}. Sequencing uses these distinct indices; diagonal sequencing variables, if stored, are fixed to zero. This follows the preceding-surgery interpretation and the explicit j ∈ I ∖{i} dual indices on source PDF page 7.

The input parameters are:

  • din ≥ 0: sampled duration of surgery i, for (i,n) ∈ I ×N.
  • cr for r ∈ R and ca for a ∈ A: the objective coefficients appearing in the room-opening cost and the anesthesiologist activation cost, respectively.
  • coa for a ∈ A and cor for r ∈ R: anesthesiologist and room overtime cost coefficients, respectively.
  • ga,wa ∈{0,1} for a ∈ A: regular-duty and on-call availability indicators.
  • κiaA ∈{0,1} for (i,a) ∈ I × A and κirR ∈{0,1} for (i,r) ∈ I × R: assignment compatibility indicators.
  • tastart,taend for a ∈ A: anesthesiologist shift start and end times; Tend: room regular end time.
  • M,Mseq,Manesth,Mroom: fixed finite big-M coefficients supplied with the instance.

All numerical coefficients and set memberships are supplied as instance data.

Decision variables

The shared first-stage binary variables are xia (anesthesiologist assignment), ya (on-call activation), zir (room assignment), vr (room activation), uij (precedence), and the resource-specific sequence variables αija and βijr. The continuous variable si is the scheduled start time.

For each sample n ∈N, Sin is the actual start time. Write OaA,n and OrR,n for the source variables Overan and Overrn, respectively. These are distinct anesthesiologist and room overtime variable families, regardless of whether the underlying resource labels overlap.

Deterministic equivalent

The selected formulation is the finite-sample model with each sample recourse minimum exposed as a separate continuous variable block. All first-stage variables are shared across samples. Minimize over all declared variables:

min ⁡ ∑ r∈Rcrvr + ∑ a∈Acaya + 1 Ns ∑ n∈N (∑ a∈AcoaOaA,n + ∑ r∈RcorOrR,n) . 		(1)

The term ∑ ⁡ r∈Rcrvr charges only opened rooms, restoring source equation (1).
