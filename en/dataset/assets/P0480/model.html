Reachability inputs and scope of the selected replacement

The recursion (45) is exactly the pair of propagation rows retained as (50b)–(50c). Its accompanying definitions, on physical PDF page 15, are

Zu = ⟨u(i∣k),0⟩,Z𝜖 = ⟨𝜖(k),𝜖max ⁡ ⟩,Z𝜗 = ⟨0,𝜗max ⁡ ⟩.

The set R^z(i + 1∣k) is the over-approximated reachable set of the lifted state z(i + 1∣k), and R^(i + 1∣k) is that of the physical state x(i + 1∣k). Appendix B assumes that the exact and over-approximated lifted reachable sets originate from the same initial set. The input zonotope depends on the decision u(i∣k); the disturbance zonotope is centered at the measured head-vehicle velocity, and the attack zonotope is centered at zero. The zero-attack and zero-noise assumptions of the earlier nominal controllers are not imposed on (50).

Printed scope and omissions. The printed initialization (50h) specifies only R^(0∣k), whereas (50b) needs R^z(0∣k). Neither the selected block nor the linked initialization passages give a formula for this initial lifted set. It is not supplied here. Also, the source calls Z𝜖 = ⟨𝜖(k),𝜖max ⁡ ⟩ a set derived from (13), although (13) bounds the absolute disturbance about zero, not its variation about 𝜖(k). Both printed expressions are retained with their original scopes; no centered-deviation bound is substituted for (13). Finally, (50e) is interval membership and does not impose membership in the original zonotope. The superseded zonotope-membership row is not reinstated.

Scope of the appendix guarantees. Appendices C and D state recursive feasibility and closed-loop constraint-satisfaction results for problem (48), not a separate theorem for (50). Assumption 1 in Appendix C requires X to be one-step robustly control invariant under some admissible backup input ub ∈U. The closed-loop result additionally presumes disturbances, attacks, and modeling errors bounded by Z𝜖,Z𝜗,Zσ,Zϱ and feasibility at the stated time steps. These are premises of the cited guarantees, not extra terminal constraints printed in (50).

Online use

At each time step the problem is solved with the current measured state. The resulting sequences are

u∗(k) = [u∗(0∣k),u∗(1∣k),…,u∗(N − 1∣k)],x∗(k) = [x∗(1∣k),x∗(2∣k),…,x∗(N∣k)].

Only the first input u∗(0∣k) is applied to the CAV; the time is incremented and the measured state is updated. Algorithm 1 lists pre-collected (U,E,F,X), constraints (X,U), weights (Q,R), bounded sets (Z𝜖,Z𝜗,Zω), horizon N, and total steps Ns as inputs, and runs while 0 ≤ k ≤ Ns. It lists Zω without a general defining formula; (50) instead uses the modeling-error zonotopes (38). No additional noise-zonotope construction is inserted into the selected optimization problem.
