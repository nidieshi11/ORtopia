Integrated Stochastic Self-Scheduling in Two-Settlement Markets

The current model uses a scenario tree with a given pre-dispatch state at node 0. Write Δ > 0 for period length in hours. Power variables are in MW, storage in MWh, energy prices/costs in monetary units per MWh, and ramp limits in MW per hour. V (i) is the set of descendants of i, including i, and

Hr(i) = {k ∈V (i) : 0 ≤ t(k) − t(i) ≤ r − 1}.

Thus minimum-up/down time is enforced forward along every scenario branch. This definition follows the paper, PDF page 9. The piecewise-linear cost ordinates ϕm already include Δ times the hourly input values. Capacity bounds and optional terminal storage are supplied in each instance. Initial thermal state is given and s0 = 0. Startup/shutdown logic now also applies at the root; this explicit correction prevents a fictitious shutdown credit when a previously-off unit starts.
