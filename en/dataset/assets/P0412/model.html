Algorithm and input scope

The code searches service counts and departure-time neighborhoods, and constructs feasible passenger flows by boarding as many as available capacity allows. Greedy boarding and the search neighborhoods are algorithm choices for candidate construction. The full supplied scenario set is evaluated for every candidate. This is a verified feasible heuristic with full scenario evaluation. The two delivered instances retain respectively one line/five demand scenarios and two lines/one scenario with 44 physical stations in total. Their time horizons are the supplied input horizons, specified separately for each instance.
