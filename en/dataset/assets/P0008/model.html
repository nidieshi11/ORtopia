Application scope and parameters

Select the ”Flexible OST Scheduling and Routing MIP” option for the paper. This approach involves optimizing daily paths and sample transfer processes within a given limited planning period T = {1,…,T}.

Among the locations V = {1,…,n + 1}, 1 is the district hub, 2,…,n is the set of other health facilities, and L = n + 1 is the set of molecular laboratories. The specimen sources are I = {1,…,n}. The arcs are directed, as specified in A = {(i,j) : i,j ∈ V,i≠j}, with symmetric travel distances Dij = Dji ≥ 0 and Dii = 0. Parameters ct,Ht,Rt denote the number of couriers per day, the maximum number of non-hub stops per route, and maximum mileage per route, respectively. The full-horizon and first-week mileage budgets are B,B1 and W1 = {1,…,min ⁡ (7,T)}, respectively. Let V t = {1}∪{i ∈ V ∖{1} : 2D1i ≤ Rt} denote the serviceable locations for the day. All arcs incident to V ∖ V t and all visits to those locations are fixed to zero. The auxiliary sequence and distance variables are defined only for V t ∖{1}. The waiting cost accounts for all specimen inventory and transfers at the sources in I, including inventory at sources inaccessible that day. Both Ht ≥ 1 and ct ≥ 0 are integers. This daily node screening explicitly implements the necessary service-radius condition in the original equation (26). To retain the distance constraints in equations (26)–(27), which use Rt as the activation constant, the input must also satisfy Dij ≤ Di1 + D1j, the triangle inequality via the hub. Euclidean distances and shortest-path distances in the same undirected network satisfy this condition. The synthetic experiment on page 25 uses Euclidean distances, while page 33 notes that the operational distance matrix was adjusted using courier records. This Rt formulation applies to distances satisfying the stated triangle inequality.

ui(t) represents the known daily arrival of samples. s¯ik ≥ 0 indicates the inventory levels of various sources at the beginning of the planning period, during phase k = 1,…,7. ρk ≥ 0 refers to the inventory penalties at the end of the period.
