Basis and scope of the revision

It is necessary to retain the original quantities for each case, namely 4/64/192 periods. Additionally, certain battery/power limits should be maintained. The values for non-zero heterogeneous driving costs, 4-hour sampling intervals, and limited time-based pricing should also be preserved. Finally, a target battery capacity of 70% should be established for the terminal. These parameters are determined based on the local scenario.

Retained Core Model

According to the tex formulas and the PDF, the directly solvable core model is the linear programming reformulation on Page 20, denoted by (RK″). The original continuous-time robust problem (R) on Page 13 and the intermediate robust counterpart (RK′) on Page 19 are omitted because they are intermediate non-convex or semi-infinite formulations. The paper proves that the original robust V2G problem is exactly equivalent to the linear program retained below.

Decision variables. For each period k ∈K, xkb is the baseline charging power, xkr is the regulation bid, mk is an auxiliary epigraph variable, and z is the epigraph variable for the terminal piecewise-affine penalty. The additional variables λk+,λk−,𝜃k+,𝜃k−,Λk,l+,Λk,l−,Θk,l+,Θk,l− are dual variables introduced by robust optimization.

Parameters and index sets. The feasible charging set is XK. The bounds ȳk+,ȳk−,ȳ,y̲,ȳ0,y̲0,ȳ^0,y̲^0 are battery and initial-state limits. The parameters η+,η−,Δt,γ,γ^,dk,rn,qn are as in the paper, with Δη = 1 η− − η+ > 0. The terminal penalty is represented by breakpoint sets N+,N−,N0. The horizon indices are I(k,l) = min ⁡ {k,l + Γ∕Δt − 1} and Î(K,k) = min ⁡ {K,k + Γ^∕Δt − 1}.

Current non-degradable operational data

Each instance retains the same number of time periods, as well as a limited battery and power range. dk > 0 represents the heterogeneous driving energy consumption rate, with terminal segmentation penalties set to max ⁡ {0,.6(y − 0.7ȳ),.6(0.7ȳ − y)}; efficiency is denoted as η+ = η− = .85. Time periods consist of 4-hour operating windows, with specific pricing, initial battery levels, and legal uncertainty ranges determined by the instance itself. Cases with zero demand are stored as historical reference data.
