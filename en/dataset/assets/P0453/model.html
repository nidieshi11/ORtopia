max ⁡ ∑ t=1Tf(x t;𝜃t) s.t. ∑ t=1Tg i(xt;𝜃t) ≤ ci,i = 1,…,m, xt ∈X, t = 1,…,T. 		(PCP)

Decision variables and fixed data (pp. 7–8). The decision variables are (x1,…,xT). The horizon consists of T discrete time periods, and i = 1,…,m indexes the budget constraints. The quantity ci is the initial capacity of budget i. The action set satisfies

X ⊂ ℝk,X is compact and convex.

For the full-horizon program, the realized parameters are data, not decision variables:

𝜃t ∈ Θ ⊂ ℝl,t = 1,…,T.

The functions f and g are known a priori. In this selected version they are deterministic given the action and parameter; the additional randomness in reward and consumption introduced in Section 6.4 is not used here. No relationship between the horizon T and the initial budget is assumed (p. 18).

Inherited function classes and parameterization (pp. 7–8). The spaces used in the underlying definition are

F = F(X) = {u : X → ℝ : u is concave and continuous on X}, G = G(X) = {u : X → ℝ : u is convex and continuous on X}, ft ∈F, t = 1,…,T, git ∈G, i = 1,…,m,t = 1,…,T.

The parameterization displayed on the original p. 8 is

ft(xt) := f(xt;𝜃t),git(xt;𝜃t) := gi(xt;𝜃t),i = 1,…,m,t = 1,…,T.

The vector-valued constraint function used in (PCP) is

g(x;𝜃) =(g1(x;𝜃),…,gm(x;𝜃))⊤ ⁡ : X → ℝm.

The inherited time-indexed vector function is printed on p. 7 as

gt(x) =(g1t(x),…,gmt(x))⊤ ⁡ : ℝk → ℝm.

Notation discrepancies retained: the original p. 8 image includes the extra parameter argument on the left-hand side of the definition of git, whereas p. 7 writes git(x). Also, p. 7 prints the domain of gt as ℝk although its component function classes are supported on X. The selected p. 8 definition of g has domain X; no extension outside that set is supplied here.

Parameter space and probability measures (pp. 8–9). For 𝜃,𝜃′∈ Θ, the paper defines

ρ(𝜃,𝜃′) := sup ⁡ x∈X ∥(f(x;𝜃),g(x;𝜃)) −(f(x;𝜃′),g(x;𝜃′))∥ ∞. 		(2)

Here ∥⋅∥∞ is the supremum norm in ℝm+1. The authors take Θ to be a set of class representatives, so that

ρ(𝜃,𝜃′) > 0for every 𝜃≠𝜃′ in Θ.

The sigma-algebra BΘ is the smallest sigma-algebra containing all open subsets of Θ under the metric ρ. The distribution Pt of 𝜃t is a probability measure on (Θ,BΘ).

Standing input assumptions (Assumption 1, p. 9). These are restrictions on the functions, action set, and stochastic input, separately from the decision constraints in (PCP).

(a) |f(x;𝜃)|≤ 1 ∀ ⁡x ∈X,∀ ⁡𝜃 ∈ Θ; (b) gi(x;𝜃) ∈ [0,1] ∀ ⁡x ∈X,∀ ⁡𝜃 ∈ Θ,i = 1,…,m; 0 ∈X,gi(0;𝜃) = 0 ∀ ⁡𝜃 ∈ Θ,i = 1,…,m.
(c)∃ ⁡q > 0such that∀ ⁡𝜃 ∈ Θ,∀ ⁡i = 1,…,m,∀ ⁡x ∈X,gi(x;𝜃) > 0⟹f(x;𝜃) ≤ q ⋅ gi(x;𝜃).
(d)𝜃t ∼Pt,t = 1,…,T.

The accompanying printed independence condition is: “Pt’s are independent with each others.” This wording attaches independence to the distributions themselves; it is retained rather than replaced by an additional probabilistic equation. The surrounding stochastic-input description uses independent draws across periods, does not require identical distributions, and permits dependence between components of (f,g). Exact knowledge of the distributions is not assumed in the general model.

(e)f(x;𝜃) is concave over x, gi(x;𝜃) is convex over x,∀ ⁡𝜃 ∈ Θ,i = 1,…,m.

Condition (c) applies only when the indicated consumption is strictly positive. In particular, the displayed assumptions do not impose a reward normalization at the zero action. Appendix A4 (p. 47) nevertheless invokes a zero objective value at that action; that later proof statement is not added as a condition of (PCP).

Scope of the selected form (pp. 7–8 and 11–12). The paper adopts (PCP) as the underlying problem for its first-observe-then-decide online setting: the current parameter, and hence the current reward and consumption functions, is observed before the current action is chosen. The displayed full-horizon program is the offline benchmark, not an optimization over online policies. The online history restriction, regret measure, expected-value relaxation, dual problems, and algorithmic subproblems therefore do not add rows to (PCP).
