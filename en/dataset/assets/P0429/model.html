Piecewise-Linear Value Reformulation


Sets and indices

Let N be a finite node set and let E ⊆N ×N be a finite directed-edge set. Let Eh ⊆E be the set of candidate edges and Nh ⊆N the set of candidate nodes. For every i ∈Nh, let Eh−(i) ⊆Eh and Eh+(i) ⊆Eh denote the designated incoming and outgoing candidate-edge sets, respectively, and define the incident candidate-edge set

Eh(i) := Eh−(i) ∪E h+(i).

Let S ⊆N ×N be the finite set of origin–destination pairs, indexed by (o,d). Let R be the finite row-index set for the flow-balance equations.

Parameters

  • qod ∈ ℝ+: weight of OD pair (o,d) ∈S.
  • c = (cij)(i,j)∈Eh ∈ ℝ|Eh|: candidate-edge cost vector.
  • b = (bi)i∈Nh ∈ ℝ|Nh|: candidate-node cost vector.
  • Bedge,Bnode ∈ ℝ: edge and node budgets.
  • A ∈ ℝ|R|×|E|: flow-balance matrix, whose columns are indexed by E.
  • eod ∈ ℝ|R|: flow-balance right-hand side for each (o,d) ∈S.
  • t = (tij)(i,j)∈E ∈ ℝ|E|: edge travel-time vector.
  • β1,β2 ∈ ℝ: affine-piece slope coefficients satisfying β1 ≤ β2.

  • T1 ∈ ℝ: breakpoint used to define the affine-piece intercepts

    α1 := 1,α2 := 1 + (β2 − β1)T1.

Decision variables

For every (o,d) ∈S, let

yod = (y ijod) (i,j)∈E ∈ ℝ|E|

be the routing-flow vector and let vod ∈ ℝ be its piecewise-linear performance value. For every (i,j) ∈Eh, let xij be the candidate-edge design variable, and for every i ∈Nh, let zi be the candidate-node design variable.

Mixed-integer linear formulation

max ⁡ v,x,y,z ∑ (o,d)∈Sqodvod (1) subject to ∑ (i,j)∈Ehcijxij ≤ Bedge, (2) ∑ i∈Nhbizi ≤ Bnode, (3) Ayod = eod, ∀ ⁡(o,d) ∈S, (4) yijod ≤ x ij, ∀ ⁡(i,j) ∈Eh,∀ ⁡(o,d) ∈S, (5) yijod ≤ x wl + zi, ∀ ⁡i ∈Nh,∀ ⁡(i,j) ∈Eh−(i),∀ ⁡(w,l) ∈E h(i),∀ ⁡(o,d) ∈S, (6) vod ≤ α 1 − β1 ∑ (i,j)∈Etijyijod, ∀ ⁡(o,d) ∈S, (7) vod ≤ α 2 − β2 ∑ (i,j)∈Etijyijod, ∀ ⁡(o,d) ∈S, (8) vod ≥ 0, ∀ ⁡(o,d) ∈S, (9) 0 ≤ yijod ≤ 1, ∀ ⁡(i,j) ∈E,∀ ⁡(o,d) ∈S, (10) xij ∈{0,1}, ∀ ⁡(i,j) ∈Eh, (11) zi ∈{0,1}, ∀ ⁡i ∈Nh.
