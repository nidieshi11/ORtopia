P0020: Integrated Car Resequencing with Painted Body Storage


Selected core model and source

The single selected model is the complete formulation (CF) for the joint upstream sequence, downstream sequence, and painted-body-storage assignment. It is the application problem in Section 3 of Guo et al., A Logic-Based Benders Decomposition for the Car Resequencing Problem with a Painted Body Storage, CIRRELT-2025-04. The local PDF gives the complete formulation in Supplement 1, PDF pages 25–27 (printed pages 23–25), equations (1)–(23). The expressions below retain that feasible set and use the exact binary product linearization already used in the local integrated solver.

Sets and fixed data

B,M,J,L,W are finite sets of bodies, colours, configurations, FIFO storage lanes, and assembly options. Demand dbmj is a nonnegative integer. Set d = ∑ ⁡ b,m,jdbmj > 0 and V = P = {1,…,d}. The positive integers c¯,q¯ are the maximum colour-run length and each lane’s capacity. A sum over an empty index set is zero. For c¯ ≥ d, the colour-window family (4) is empty. Option requirements rjw ≥ 0 and positive cost weights α,β,γ are fixed. The paper’s ideal option rate is

σw = 1 d∑ j∈Jrjw ∑ b∈B,m∈Mdbmj.

The rate is computed from demand. The input to the local solver must supply this value if the paper’s rate definition is required.

Decision variables

xbmji selects the body, colour and configuration at upstream position i; hli selects its storage lane; ypi selects its downstream position. Binary zvli means that car v leaves lane l when car i enters the storage, with v ≤ i. Variables fi,i+1,gi,i+1 represent changes in consecutive body and colour, and upw represents the absolute option-consumption deviation through downstream position p. The auxiliary variables χij and sipj give the configuration indicator and its product with ypi. Since exactly one specification is selected per car, (20a)–(20d) enforce this product exactly. All domains are stated in (22)–(25).

Reading the constraint groups. (2)–(6) specify demand, colour batching and upstream change costs. (7)–(19) couple the upstream/downstream permutations, FIFO lanes, simultaneous entrance/exit events and capacity. (20a)–(20d) are one exact linearization within the same application model; (21a)–(21b) give the paper’s absolute option deviation. The defining inequalities and assignment equalities imply nonnegative lower bounds for f,g,u.
