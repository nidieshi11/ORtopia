Jk(x) = max ⁡ E [∑ t=1kR tut] , ∑ t=1kAu t ≤ x(a.s.), ut ∈ En. 		(6)

The maximization is over acceptance processes for the given starting capacity vector x and time-to-go k. The action condition applies at each t = 1,…,k. The accompanying information restriction is

Ft = σ({Rk;T ≥ k ≥ t}),ut is Ft-measurable,t = 1,…,k.

The authors describe this as adaptation to the history of requests from k to t. Optimizing this process provides a policy only for states reachable from (x,k), which suffices to determine Jk(x).

Printed information-index qualification. The filtration above retains the printed T and the use of k inside the generating set. The surrounding prose instead describes history beginning at the starting time k. The formulation passages do not define T or explicitly relate it to that starting time; no replacement of T by k is made here.

Fixed network data, state, and time

There are m legs and n origin–destination itineraries, indexed by i = 1,…,m and j = 1,…,n. The fixed network matrix is

A = [aij],aij = number of seats on leg i used by itinerary j,

with aij = 0 if leg i is not part of itinerary j. The notation Aj denotes column j, and Ai denotes row i. The notation i ∈ Aj means that leg i is used by itinerary j, and j ∈ Ai means that itinerary j uses leg i.

Each column Aj is a multiple of the incidence vector of its itinerary; it is the incidence vector itself for a one-seat request. Requests need not use just one seat. Group requests can be represented by separate columns for possible group sizes, with the nonzero column entries equal to the group size and the itinerary revenue equal to the total group revenue.

The state is the vector of leg capacities

x = (x1,…,xm).

Selling itinerary j changes the state to x − Aj. The selected interpretation assumes no cancellations or no-shows and no overselling of legs. No additional numerical state domain is imposed beyond the source’s description of x as leg capacities.

Time is discrete and counted backwards: k is the current number of periods remaining before departure, and t denotes an arbitrary time-to-go. At most one itinerary request arrives in a period. Superscripts denote vector components and subscripts denote time, except for the explicitly defined matrix-row notation. The paper does not distinguish row and column vectors.

Request support and distribution assumptions

Define

En = {e0,e1,…,en},e0 = 0,

where ej is the jth unit n-vector for j = 1,…,n, and e0 is the zero n-vector. The request support is

S = {R : R = αe,e ∈ En,α ≥ 0}.

The exogenous request vector satisfies

Rt = (Rt1,…,R tn) ∈S,t ≥ 1.

A component Rtj > 0 means that a request for itinerary j occurred with revenue Rtj; Rtj = 0 means that no request for that itinerary occurred. The realization Rt = 0 means that no itinerary request occurred. Thus at most one component of Rt is positive.

The sequence {Rt;t ≥ 1} is independent, with known joint distributions Ft(r) supported on S. Its marginal distributions satisfy

Ftj(r) = P(R tj ≤ r),F tj is continuous on (0,+∞),E[R tj] < ∞,t ≥ 1,j = 1,…,n.

No particular order of arrival is assumed. The distributions may depend on time. The accompanying distribution interpretation is printed as

P(Rtj > 0) = 1 − F tj(0),P(R tj ≤ r∣R tj > 0) = Ftj(r) 1 − Ftj(0).

Printed inconsistency: with the preceding definition of Ftj, the displayed conditional-distribution expression does not remove the mass at zero from its numerator. It is retained as printed, without repair; the passage supplies no exceptional-case convention for a zero denominator.

The additional bounded-support premise P(Rtj ≤ C) = 1 for some constant C is expressly required for the paper’s asymptotic results, not for the adapted control problem (6), and is not imposed here.

Acceptance decisions and inherited feasible-action definition

For a current state x and realized request r = (r1,…,rn) ∈S, the acceptance decision is an n-vector with the interpretation

ukj = { 1,if a request for itinerary j is accepted at time k, 0,otherwise, j = 1,…,n.

The source describes the decision’s dependence by

ukj = u kj(x,rj),u k = uk(x,r),r ∈S.

At most one request can be accepted in a period, and acceptance cannot oversell a leg. The source-defined feasible-action set at the current inventory is

U(x) = {e ∈ En : Ae ≤ x},uk(x,r) ∈U(x).

Here x in U(x) is the inventory at the decision epoch, whereas x in (6) is the given starting inventory. The cumulative almost-sure capacity constraint in (6) is retained; no additional request-matching constraint is introduced.

Inherited value-function definition and boundary condition

The quantity Jk(x) is the maximum expected revenue for seat inventory x and time-to-go k. Its defining Bellman characterization in the original formulation is

Jk(x) = max ⁡ uk(⋅)∈U(x)E[Rkuk(x,Rk) + Jk−1(x − Auk(x,Rk))]. 		(2)

This characterizes the same value used in (6), rather than introducing another set of decision variables or a relaxation. Its boundary condition is

J0(x) = 0,∀ ⁡x. 		(3)
