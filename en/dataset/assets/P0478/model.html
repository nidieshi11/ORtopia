Sequential coordination, execution, and feedback

The three objectives are linked by the procedure in Section 4, Fig. 4, and Algorithm 1. At the high level, the input consists of basic-unit positions ξ and initial conditions w(0). The algorithm initializes

k ← 1,w(k) ← w(0),x(k) ← Aggregate ⁡ (w(k),ξ).

For k ≤ kend, the high-level solve and conversion produce

u(k) ←_ ⁡ (x(k)).

Here the left side is the action vector u(k). Only the current-step intervention decision is implemented, following the receding-horizon principle. For each intervention al, if any uj(k) = al, the subsequent calls are

tsl(k) ← MiddleLevel ⁡ (u(k),al,T^Maint), ϕ(k) ← LowLevel ⁡ (w(k),ξ,tsl(k),al).

The first call solves the selected middle-level problem; the second solves the selected clustering problem sequentially for the active slots using the sets Is above. The generic input T^Maint is the estimated time to perform the suggested intervention. The particular grinding estimator (47) and numerical case-study settings are not imposed on this generic formulation.

Only basic units inside the returned clusters are treated. If no intervention is suggested, the procedure proceeds to the condition update. New measurements are used when available; otherwise the algorithm uses the abstract simulation operation:
