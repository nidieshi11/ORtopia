A model for allocating supplies to disaster areas, taking into account emergency priorities

Source and scope Pages 10–12 of the PDF document, section 3.4, equations (17)–(25). A fixed decision-making cycle is defined as t. Demand forecasting, regional grouping, urgency levels, and inventory levels from the previous period are all known inputs for this optimization. Supply allocation in the next stage is not part of this model.

Collections, parameters, and variables

L represents the type of supplies; M represents the collection of distribution centers; G represents the groups of affected areas; Ig represents the regions to which the groups belong; g represents the collection of regions. V represents the type of transport vehicles. The values for Ig are not provided. Dil(t) ≥ 0 represents the demand, while Qml(t − 1|t − 1) ≥ 0 represents the initial inventory at the center. UNV l represents the volume per unit of supplies; UNLv represents the capacity of the vehicle; NV vm(t) represents the number of available trains for this period. CSml and CTmil represent the settings for units and transportation costs, respectively. ui1(t) represents the time elapsed since the last supply arrived. Ωg(t) represents the emergency rating value of the input groups (originally denoted as Xg(t); here, Ωg(t) is used instead). It is assumed that the normalization conditions satisfy F¯gj > F̲gj and j = 1,2. ωr,ωc ≥ 0 and ωr + ωc = 1 are also assumed to hold true.
