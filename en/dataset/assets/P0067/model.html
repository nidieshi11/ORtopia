Core form and scope The model retains F1 from Section 5.1, the complete path formulation of the authors’ approximate joint routing and dispatching policy (AJRP). It is equivalent to the current-period decision problem in equations (11)–(13) of Section 4. It uses estimated future costs to approximate the original stochastic dynamic JDR, so its objective value is that of the approximate dispatching model. For a fixed current epoch tn, optimize current routes together with the estimated driver dispatch in the remaining periods.

Equation (15) takes into account both the expected occupancy due to future deliveries, the known occupancy from previous deliveries, and the actual occupancy during this particular route. All these factors are considered within the same maximum capacity limit for the driver. Equation (20) ensures that all current orders are fully processed without any splitting or postponement to the next batch.

Text translation and boundary settings In the original PDF formula (15), the subscript ζ is replaced by ζnp. This is determined according to the status defined on page 8. Formulas (12) and Appendix A are unified as ζpn, which represents the number of drivers already known to be occupied in the future period. When n = N is applied, the sum over future periods is empty, and the model naturally retains the current optimal routing choices. When In = ∅ is applied, there are no active routes for drivers to assign passengers to; the number of drivers in the future can be zero, provided that the input costs allow it. There is no obligation to assign at least one driver per period. This model uses all feasible elementary routes. Using just a small portion of these routes would result in a restricted model, and its optimal value corresponds to the restricted model formed by the listed routes.
