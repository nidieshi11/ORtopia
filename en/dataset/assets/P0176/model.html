Rectangular-coordinate AC optimal power flow

Let B be a finite set of buses, U ⊆ B the generator buses, and L a finite set of endpoint-directed branch indices. Each a ∈ L has endpoints ka,ℓa ∈ B; distinct indices may identify parallel branches. Define δ(k) = {a ∈ L : ka = k}. All data below are fixed real scalars: demands pkd,qkd and shunt coefficients gkk,hkk for k ∈ B; branch coefficients Ga,Ba and thermal limits da+ for a ∈ L; generation bounds (pkg)±,(qkg)± and cost coefficients Ck,1,Ck,2,Ck,3 for k ∈ U, with Ck,1 ≥ 0; and voltage-magnitude bounds |V k|± for k ∈ B. For each a ∈ L, the fixed angle-bound coefficients αa− = tan ⁡ 𝜃a− and αa+ = tan ⁡ 𝜃a+ are finite.

The decision variables are pg,qg ∈ ℝ|U|, e,f ∈ ℝ|B|, and the real branch-flow auxiliaries p,q ∈ ℝ|L|. For nodal balances, define Pkg = pkg and Qkg = qkg when k ∈ U, and Pkg = Qkg = 0 otherwise. Define the following expressions.

Wk = ek2 + f k2(k ∈ B),D a = ekaeℓa + fkafℓa,Na = eℓafka − ekafℓa(a ∈ L).

The model is

min ⁡ pg,qg,e,f,p,q ∑ k∈U(Ck,1(pkg)2 + C k,2pkg + C k,3)

subject to

Pkg − p kd = g kkWk + ∑ a∈δ(k)pa (k ∈ B), Qkg − q kd = −h kkWk + ∑ a∈δ(k)qa (k ∈ B), pa = −Ga(Wka − Da) + BaNa (a ∈ L), qa = Ba(Wka − Da) + GaNa (a ∈ L), pa2 + q a2 ≤ (d a+)2 (a ∈ L), (pkg)− ≤ p kg (k ∈ U), pkg ≤ (p kg)+ (k ∈ U), (qkg)− ≤ q kg (k ∈ U), qkg ≤ (q kg)+ (k ∈ U), (|V k|−)2 ≤ W k (k ∈ B), Wk ≤ (|V k|+)2 (k ∈ B), αa−D a − Na ≤ 0 (a ∈ L), Na − αa+D a ≤ 0 (a ∈ L), Da ≥ 0 (a ∈ L).
