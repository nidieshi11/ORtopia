Scaled Deterministic Positive-Part Surrogate Routing Model


1 Sets and network

Let I,L ∈ ℤ+ be the numbers of customers and available homogeneous vehicles, respectively. Define

Nc := {1,…,I},Nd := {I + 1,…,I + L},N := {0}∪Nc ∪Nd,

where node 0 is the depot, Nc is the customer set, and Nd is the set of dummy destination nodes. The directed arc set is

A := Ao ∪Ac ∪Ad,

with

Ao := {(0,j) : j ∈Nc},Ac := {(i,j) : i,j ∈Nc,i≠j},
Ad := {(i,ℓ) : i ∈Nc,ℓ ∈Nd}.

For every H ⊆N, define the outgoing and incoming cut sets

E+(H) := {(i,j) ∈A : i ∈H,j ∈N ∖H},
E−(H) := {(j,i) ∈A : i ∈H,j ∈N ∖H}.

For a singleton node i ∈N, write E+(i) := E+({i}) and E−(i) := E−({i}).

2 Parameters

For each customer i ∈Nc, let di denote its demand, and let Q > 0 be the homogeneous vehicle capacity. Let τ ∈ ℝ be the common threshold. Let

T ∈ ℤ+,ρ ∈ ℝ+.

For every t ∈{1,…,T} and a ∈A, 𝜃at ∈ ℝ is a fixed coefficient, and 𝜃¯t ∈ ℝ is a fixed intercept. Thus, for each t, the coefficient vector 𝜃t = (𝜃at)a∈A has dimension |A|.
