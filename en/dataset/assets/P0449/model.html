Scope, data, and variable roles

The planning horizon, locations, vehicle types, and movement modes are respectively

T = {1,…,T},I,Kwith |K| = 1,L = {0,…,L}.

As in Section 2 of the paper, the vehicle-type superscript is dropped throughout this formulation. R is the total number of available vehicles; it is distinct from the state-transition function Rt+1π below. Movement mode 0 denotes empty repositioning; the remaining modes denote carrying different types of loads.

The decision xijlt is the number of vehicles dispatched from location i to location j at time t using movement mode l. The fixed coefficient cijlt is the cost of dispatching one such vehicle. The state component rit is the number of vehicles available at location i at time t. Thus rt is given in the period-t problem, whereas rt+1 is determined by that problem. The variables zj,t+1(q) embed the supplied piecewise-linear continuation functions; they are not additional vehicle types or load types.

Dijlt is the random number of loads requiring transport from i to j at time t in movement mode l, and dijlt denotes a particular realization. Suppressing indices denotes the vector of components ranging over those indices; in particular,

rt = {rit : i ∈I}, dt = {dijlt : i,j ∈I,l ∈L}, d = {dijlt : i,j ∈I,l ∈L,t ∈T} = {dt : t ∈T}.

Empty repositioning movements are unbounded in load availability:

Dij0t = ∞for all i,j ∈I,t ∈T.

If carrying load type l with the sole vehicle type is infeasible, the paper encodes this by

cijlt = ∞for all i,j ∈I,t ∈Tfor that load type l.

The paper says that usually cijlt < 0 for l ∈L ∖{0}; this is not imposed as a universal input restriction.

Travel between any pair of locations takes one time period. There is no advance information about future loads. Loads not covered in the current period are served by an emergency subcontractor and immediately leave the system. The model uses cost minimization to express the intended maximization of expected profit over the finite horizon. The stochastic assumption stated in Section 1 is that, given rt, Dt is independent of {Dt′ : t′ = 1,…,t − 1}. The paper also assumes throughout that ct is perturbed by small random amounts to obtain a single optimal solution and properly defined decision and transition functions; it specifies no perturbation magnitude or distribution.

Inherited feasible set and policy definition

The feasible set used to define the policy consists of the dispatch decisions and the next-period state they generate. Specializing the defining rows (1)–(4) to |K| = 1 and dropping the type superscript gives

Y (rt,dt) = {(xt,rt+1) : ∑ j∈I ∑ l∈Lxijlt = rit for all i ∈I, ∑ i∈I ∑ l∈Lxijlt − rj,t+1 = 0for all j ∈I, xijlt ≤ dijlt for all i,j ∈I,l ∈L, xijlt ∈ ℤ+ for all i,j ∈I,l ∈L }. 		(1–4, single type)

These are the inherited physical constraints already represented in (12), (13), (15), and (17), rather than an additional formulation to be solved.

A Markovian deterministic policy has decision functions Xtπ(⋅,⋅) mapping (rt,dt) to xt, and transition functions Rt+1π(⋅,⋅) mapping (rt,dt) to rt+1, for t ∈T. For the supplied approximations, the defining equation is

(Xtπ(r t,dt),Rt+1π(r t,dt)) = argmin ⁡ (xt,rt+1)∈Y (rt,dt) {ct ⋅ xt + V ~t+1π(r t+1)}. 		(10)

Equation (11) with (12)–(17) is the paper’s explicit embedding of this same policy definition. The exact optimal-value-function equations (7)–(8) are replaced by the supplied approximation in (10); they are not imposed on π.
